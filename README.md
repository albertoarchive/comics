# Archivo Galáctico

Biblioteca web para leer tus propios cómics de Star Wars (`.cbz` y `.cbr`), organizados por serie y por era.

- Todo se ejecuta en el navegador: los archivos no se suben a ningún servidor.
- La biblioteca se guarda en el propio navegador (IndexedDB).
- Lee `.cbz`/ZIP y `.cbr` en RAR 2.9–4.x (sin PPMd, sin cifrar y no sólidos). RAR5 no está soportado.
- Series agrupadas por nombre de archivo o por carpeta; la era se adivina por el nombre y se puede cambiar.
- Lector con doble página, modo manga, ajuste de alto/ancho y progreso guardado.

No incluye ningún cómic: añade tus propios archivos.

Se publica tal cual en Netlify (es un único `index.html`).
